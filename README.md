# Tab releases

Downloads for **Tab**, a pre-alpha web browser built from scratch. https://gettab.dev

Only the **latest** build is published here. Every older build is removed when a new one ships:
demo builds insist on updating 7 days after they're built, so everyone stays on the current one.

Install (Linux x86-64):

```sh
curl -fsSL https://gettab.dev/install.sh | sh -s -- --demo
```

Pre-alpha: no security audit yet. Don't use it for banking, trading or important logins.
Lots of real sites still break, despite the conformance numbers. Report what you find to
[@JacoblAmi1 on X](https://x.com/JacoblAmi1).

This repository holds release files only; there is no source code here.
